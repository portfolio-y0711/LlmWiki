## 📖 2. 영상 주요 주제 (추상화된 목차)

*   **[도입 및 배경]**

    - **세부 주제:** Andrej Karpathy(Tesla AI 전 이사, OpenAI 창립 멤버)의 LM 지식 베이스 포스트에서 영감을 받아 만들어진 Graphify의 등장 배경 및 핵심 가치 소개
    - **세부 주제:** 기존 LLM의 문제점 — 매번 원본 파일이나 문서를 직접 읽어 토큰을 낭비하는 구조. Graphify는 이를 지식 그래프로 인덱싱해 토큰 70% 절감, 속도 향상, 정확도 개선을 동시에 달성

*   **[설치 및 초기 환경 세팅]**

    - **세부 주제:** 사전 조건: Python 3.10+, UV 패키지 매니저 설치 (UV = Python용 NPM에 해당)
    - **세부 주제:** `graphify install` 명령으로 Claude Code, Codex, Open Code, Hermes 등 다양한 AI 에이전트에 스킬 등록 — `.claude` 폴더와 `claude.md` 파일이 자동 생성됨

*   **[지식 그래프 빌드 및 결과 해석]**

    - **세부 주제:** `/graphify .` 명령으로 현재 폴더 전체 그래프 생성. 추출 범위 3가지 선택지: ① 코드 전용, ② 코드+문서(이미지 제외), ③ 전체(이미지 포함, 200k~400k 토큰 소모)
    - **세부 주제:** 산출물 3종: `graph.html`(인터랙티브 시각화), `graph.json`(원시 그래프 데이터), `graph.reports`(분석 리포트). 실습 기준 70,000개 노드, 33개 엣지, 토큰 27배 절감 달성

*   **[핵심 기능 탐색]**

    - **세부 주제:** `graph.html` — 노드/엣지를 브라우저에서 인터랙티브하게 필터링하며 코드 연결 관계를 시각적으로 탐색
    - **세부 주제:** `path` — 두 파일/기능 간 최단 경로 탐색. 예: admin panel → AI chat 사이의 연결 파일(`index.ts`)을 자동 발견
    - **세부 주제:** `explain` — 특정 개념이나 기능을 지식 그래프 기반으로 자연어로 설명. 예: admin console의 inbound vs outbound 차이 설명
    - **세부 주제:** `query` — 자유 질문 형식으로 코드베이스에 질의. `--update` 플래그로 변경된 파일만 재추출하여 지식 베이스 갱신 가능

*   **[확장 기능 및 활용 가능성]**

    - **세부 주제:** Obsidian 볼트 생성(`--obsidian`), SVG 내보내기, Wiki 생성, Neo4j 연동(RAG 시스템 구축), MCP 서버 생성(다른 LLM이 그래프를 쿼리 가능)
    - **세부 주제:** 특히 코드베이스를 읽고 탐색하는 용도(Research, 새 코드베이스 이해)에 최적화 — 쓰기보다 읽기에 집중하는 사용자에게 추천

*(참고: 이 항목은 영상의 논리적 구조를 추상화하여 그룹화한 것이며, 시간 정보는 포함되지 않습니다.)*

## ⏳ 3. 주요 시간대별 상세 요약

*   **[00:00:00] ~ Graphify 소개 및 영상 개요**

    - Andrej Karpathy의 X 포스트를 기반으로 탄생한 Graphify 저장소 소개. 코드·문서 폴더를 지식 그래프로 변환하여 LLM 토큰 사용량을 70% 절감하고 응답 속도와 정확도를 향상시키는 도구임을 설명
    - 영상에서 다룰 내용 예고: 설치, 파일→지식 그래프 변환, 정보 추가, 쿼리, 다양한 LLM 연동, 문서 추출 등

*   **[00:01:30] ~ 커뮤니티 및 강의 소개 (광고 구간)**

    - 발표자가 운영하는 AI 에이전트·자동화 커뮤니티 소개. Amazon·Microsoft 전 시니어 AI 엔지니어 출신으로, 100개 이상의 영상 자료·템플릿·워크플로우와 주간 라이브 콜(Claude Masterclass 포함) 제공

*   **[00:02:10] ~ 설치: Python, UV, Graphify**

    - 선행 조건: Python 3.10 이상(`python.org`에서 설치), UV 패키지 매니저 설치
    - 터미널에서 순서대로: ① Python+UV 설치 명령 실행, ② `uv tool install graphify` 명령으로 Graphify 패키지 설치
    - `graphify install` 실행 시 `.claude` 폴더와 `claude.md` 파일이 생성되며 Claude Code에 스킬이 등록됨. Codex, Open Code, Hermes 등 다른 플랫폼 대응 명령도 별도 제공

*   **[00:04:00] ~ 지식 그래프 빌드: /graphify .**

    - 실습 대상: AI 영수증·은행명세서 관리 SaaS(`bookzero.ai`) 코드베이스 — app, assets, components, content, docs 등 다수 폴더 포함
    - `/graphify .` 명령 입력 후 추출 범위 선택 메시지 표시: ① 코드 전용(빠름), ② 코드+문서(중간), ③ 전체(이미지 포함, 200k~400k 토큰). 발표자는 속도를 위해 코드 전용 선택

*   **[00:05:30] ~ 그래프 생성 결과 확인**

    - 생성 완료 후 산출물 3종 확인: `graph.html`, `graph.reports`, `graph.json`
    - 실습 코드베이스 기준 노드 약 70,000개, 엣지 33개 생성. 토큰 절감 벤치마크 결과: LLM 질의 시 기존 대비 약 **27배** 토큰 절감 효과 달성
    - GRAPH_REPORT에서 God Nodes(핵심 허브 노드), Surprising Connections, Suggested Questions 항목 제공

*   **[00:06:30] ~ graph.html 인터랙티브 시각화 탐색**

    - 브라우저에서 `graph.html`을 열면 전체 코드베이스의 노드·엣지가 시각화됨
    - 특정 노드(예: Admin Layouts, API Routes) 외 나머지를 필터로 숨겨 관심 영역만 집중 탐색 가능 — 코드 연결 관계를 직관적으로 파악하는 데 효과적

*   **[00:07:30] ~ path 기능: 두 컴포넌트 간 최단 경로 탐색**

    - `/graphify path "admin panel" "AI chat"` 실행 시 두 기능을 연결하는 경로(파일 체인) 자동 탐색
    - 결과: `index.ts`가 admin layout과 AI chat 페이지 모두를 호출하는 공통 연결 파일임을 발견. 코드베이스 내 숨겨진 의존성을 즉시 파악 가능

*   **[00:08:30] ~ explain 기능: 개념·기능 자연어 설명**

    - `/graphify explain "inbound and outbound inside admin console"` 요청 시 지식 그래프 기반으로 개념 설명 생성
    - 결과: Outbound Analytics(방문자 유입 경로·이탈 지점)와 Inbound(회원가입 후 사용자 행동·이탈) 차이를 명확히 설명

*   **[00:09:30] ~ query, --update, --obsidian 등 추가 기능**

    - `query`: 자유 질문 형식으로 코드베이스에 질의
    - `--update`: 수정된 파일만 선택적으로 재추출하여 지식 베이스에 반영 (다수 파일 일괄 처리 가능)
    - `--obsidian`: 특정 폴더(예: `/docs`)를 대상으로 Obsidian 볼트 생성 — 전체 코드베이스 대신 문서 폴더만 선택적 처리 가능

*   **[00:10:30] ~ 확장 기능 및 마무리**

    - Wiki 생성, SVG 내보내기, Neo4j 연동(GraphRAG 시스템 구축), MCP 서버 생성(다른 LLM이 그래프를 직접 쿼리) 등 다양한 옵션 언급
    - 핵심 활용 방향 정리: 코드베이스 쿼리, 정보 추출, 컴포넌트 간 연결 관계 파악, 코드베이스 이해 가속화
    - 저장소 링크는 설명란에 제공. 구독·좋아요 요청 후 마무리
