## 📝 1. 영상 전체 요약

> Claude Code 등 코딩 에이전트가 시각적으로 취약하다는 한계를 극복하기 위해 제작된 **Excalidraw 다이어그램 스킬**을 소개한다. JSON 생성 → PNG 렌더링 → 자가 검증 → 반복 수정이라는 자동화된 루프를 통해, 에이전트가 스스로 시각적 결과물을 검토하고 개선하는 워크플로우를 공유하며, 설치 방법·핵심 철학·커스터마이징 방법까지 상세히 다룬다.

## 📖 2. 영상 주요 주제 (추상화된 목차)

*   **도입 — 코딩 에이전트의 시각적 한계와 해결 방향**

    - **세부 주제:** 코딩 에이전트의 문제 — 시각적 설명 요청 시 텍스트 위주의 빈약한 결과물을 생성하며, 전문적인 다이어그램 제작에 적합하지 않음
    - **세부 주제:** 해결책 — Excalidraw 다이어그램 스킬: 에이전트에게 "시각적으로 논증하는 능력"을 부여하는 커스텀 스킬

*   **핵심 기능 — 스킬 설치와 자동화 워크플로우**

    - **세부 주제:** 스킬 설치 방법 — GitHub 레포 클론 → `.claude/skills/excalidraw-diagram/` 폴더에 복사; 어떤 코딩 에이전트에서도 동작
    - **세부 주제:** 자가 검증 루프 — JSON 생성 → Python 스크립트로 PNG 렌더링 → 에이전트가 이미지를 직접 보고 결함 판단 → JSON 직접 수정 (2~4회 반복)
    - **세부 주제:** 다이어그램 복잡도 감지 — 단순 다이어그램은 한 번에 생성, 복잡한 다이어그램은 섹션별 분할 생성 (Claude Code의 32,000 토큰 출력 제한 대응)

*   **심화 — 설계 철학과 커스터마이징**

    - **세부 주제:** 핵심 철학 "시각적 논증(Argue Visually)" — 텍스트를 제거해도 구조와 레이블만으로 개념이 전달되어야 함; 두 가지 자기 검증 질문 내장
    - **세부 주제:** skill.md의 설계 패턴 — 박스 나열 금지, 멀티줌 아키텍처, 컬러 시스템, 교육적 증거 아티팩트 등 다양성을 위한 지침
    - **세부 주제:** 컬러 팔레트 커스터마이징 — 브랜드 색상 변경, hex 코드 지정, 엘리먼트 템플릿 수정으로 개인화 가능

*   **결론 — 실용적 가이드라인과 활용 범위**

    - **세부 주제:** 첫 결과물은 항상 불완전 — LLM이 색상·형태·레이아웃·위치 등 수많은 마이크로 결정을 동시에 처리하기 때문; 2~3회 반복으로 완성도 향상
    - **세부 주제:** 활용 범위 — PDF·YouTube 스크립트·코드베이스·리서치 결과·텍스트 등 모든 입력 소스에 적용 가능

*(참고: 이 항목은 영상의 논리적 구조를 추상화하여 그룹화한 것이며, 시간 정보는 포함되지 않습니다.)*

## ⏳ 3. 주요 시간대별 상세 요약

*   **[00:00:00] ~ 도입 — 코딩 에이전트의 시각적 한계**

    - 코딩 에이전트는 시각적 설명에 약함 — 다이어그램 요청 시 단순하고 획일적인 결과물을 반복 생성
    - 본인은 Excalidraw를 월 수십 개씩 사용하여 콘텐츠 제작 — 이 워크플로우 전체를 스킬로 패키징
    - 목표: 코딩 에이전트에게 "시각적으로 논증하는 능력" 부여



*   **[00:01:30] ~ 스킬 설치 방법**

    - GitHub 레포 클론 → `.claude/skills/excalidraw-diagram/` 폴더에 전체 복사
    - `skill.md` = 에이전트가 Excalidraw JSON을 생성하는 방법을 안내하는 핵심 지침서
    - Claude Code 외 모든 코딩 에이전트에서 작동
    - 설치 지원: 에이전트에게 "Excalidraw 다이어그램 스킬 설정 도와줘"라고 요청하면 README를 읽고 자동으로 수동 단계를 수행



*   **[00:02:30] ~ 기본 사용법과 자가 검증 루프**

    - 사용 예시: "이 파일/스크립트/PDF를 설명하는 다이어그램 만들어줘" → 에이전트가 스킬을 로드하고 JSON 생성
    - 렌더링: excalidraw.com에서 로컬 파일 로드 또는 Obsidian Excalidraw 플러그인 사용 (excalidraw.com 무료)
    - **자가 검증 루프**: JSON 생성 → Python 스크립트로 PNG 렌더링 → 에이전트가 PNG를 직접 시각적으로 검토 → 시각 흐름·정보 위계 등 결함 발견 → JSON 직접 수정 (2~4회 반복)
    - 결과: 직접 확인 없이도 훨씬 완성도 높은 시작점 확보



*   **[00:05:00] ~ 첫 결과물의 불완전함과 반복 개선**

    - 메타 다이어그램(워크플로우 설명용) 예시: 초안은 화살표 어색함, 색상 불만족, 정보 부족 등 아쉬운 점 존재
    - 2~3회 피드백 반복으로 만족스러운 결과물 도달
    - 불완전한 이유: LLM이 색상·형태·레이아웃·위치 등 수백 가지 마이크로 결정을 동시에 처리해야 하므로 완벽은 어렵지만, 좋은 시작점을 빠르게 제공하는 것이 핵심 가치



*   **[00:07:00] ~ 워크플로우 단계별 설명**

    - **① 아이디어 입력**: 이미 만들 다이어그램 주제를 알고 있다고 가정
    - **② 깊이 평가**: 단순 vs 복잡 다이어그램 판단 → 복잡한 경우 섹션별 분할 생성 (32,000 토큰 출력 제한 대응)
    - **③ 패턴 매핑**: 필요한 형태·텍스트 구성 설계 → JSON 파일 생성
    - **④ 검증 루프**: PNG 렌더링 → 이미지 검토 → 결함 수정 (JSON 직접 편집, 2~4회 반복)
    - **⑤ 결과 반환**: 완성된 `.excalidraw` JSON 파일



*   **[00:09:00] ~ skill.md 핵심 설계 철학 및 커스터마이징**

    - **핵심 철학 "Argue Visually"**: 텍스트를 모두 제거해도 구조·레이블만으로 개념 전달 가능해야 함
    - **두 가지 자기 검증 질문**:
      1. "시각 구조가 개념의 작동 방식을 반영하는가?"
      2. "이 다이어그램에서 구체적인 무언가를 배울 수 있는가?"
    - **skill.md 내 설계 패턴**: 박스 나열 금지, 멀티줌 아키텍처, 컬러 시스템, 교육적 증거 아티팩트
    - **커스터마이징 포인트**:
      - `color_palette` 파일: 브랜드 색상(hex 코드)으로 변경 가능 ("파란색 대신 보라+노란색 써줘"처럼 요청)
      - 엘리먼트 템플릿 수정으로 원하는 스타일 적용
      - 기본 설정으로도 즉시 사용 가능



*   **[00:11:30] ~ 마무리 — 활용 범위와 권장 사항**

    - 입력 소스 제한 없음: PDF·YouTube 스크립트·코드베이스·리서치 결과·일반 텍스트 모두 가능
    - 주당 수 시간 절약 효과 체감
    - 시작 권장: 레포 클론 → 스킬 설치 → PDF나 코드베이스 대상으로 즉시 테스트
