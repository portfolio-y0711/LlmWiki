## 📖 2. 영상 주요 주제 (추상화된 목차)

*   **[배경: Claude Code 품질 저하 및 OpenAI 업데이트]**

    - **세부 주제:** Claude Code 품질 저하 3가지 원인 — ① 기본 추론 난이도 높음→중간 변경(현재 원상 복구), ② 1시간 이상 비활성 세션의 사고 과정 캐시 초기화, ③ 출력량 절감 목적 시스템 프롬프트 변경
    - **세부 주제:** OpenAI 최신 업데이트 — Image 2.0(한글 포함 고품질 이미지 생성), GPT-5.5 모델 출시로 Codex 사용 최적 시점 도래

*   **[설치 및 기본 UI 설정]**

    - **세부 주제:** npm으로 Codex 설치, `codex` 명령으로 실행. Claude Code와 유사한 터미널 UI
    - **세부 주제:** `/permissions`: 3가지 모드 — ① Default(파일 읽기/수정 자유, 외부 접근 시 승인 요청), ② Auto Review(서브 에이전트가 명령 안전성 판단), ③ Full Access(모든 명령 자율 실행)
    - **세부 주제:** `/statusline`: 모델명·reasoning 단계·git 브랜치·컨텍스트 사용량·Fast 모드 여부·프로젝트명 등 스테이터스 라인 커스터마이징

*   **[세션 관리 및 생산성 단축키]**

    - **세부 주제:** Tab 키: 현재 작업 중단 없이 후속 작업을 큐에 예약 등록. 장시간 작업 중 다음 단계 미리 입력 가능
    - **세부 주제:** `/copy` (Ctrl+O): 마지막 응답을 클립보드에 복사. 다른 에디터·세션으로 결과 활용
    - **세부 주제:** `/clear`: 대화 내역 완전 초기화, 새 세션 시작. 기능 단위로 새 세션을 여는 것을 권장
    - **세부 주제:** 프롬프트 히스토리: 방향키로 이전 프롬프트 탐색, Ctrl+R로 프롬프트 검색. Ctrl+C로 입력 중인 프롬프트 삭제 후 히스토리 저장(이후 방향키로 복구)
    - **세부 주제:** `codex resume`: 현재 디렉터리의 이전 세션 목록 확인 및 복구. `--all` 옵션으로 전체 프로젝트 세션 일괄 조회
    - **세부 주제:** `/fork`: 현재 세션을 동일한 대화 맥락 그대로 복제해 분기 세션 생성. 기존 작업 유지하면서 새 기능 실험 시 활용
    - **세부 주제:** `/status`: 현재 세션의 컨텍스트 윈도우 사용량·weekly limit 확인
    - **세부 주제:** `/compact`: 기존 대화 맥락을 에이전트가 핵심만 추려 압축. /clear 없이 맥락 유지하며 컨텍스트 최적화

*   **[모델 및 성능 최적화]**

    - **세부 주제:** Codex Spark 모델: 성능 대비 속도 우선 모델. 일상적 빠른 코드 생성에 적합. 별도 사용량 한도로 전체 quota 절약 가능
    - **세부 주제:** `/model`: 모델 변경 + reasoning 단계(낮음→높음) 선택. reasoning high 권장
    - **세부 주제:** `/fast`: Fast 모드 토글(기본 OFF). 응답 속도 향상. GPT-5.5(2.5배 크레딧), GPT-5.4(2배 크레딧) 소모 주의

*   **[플랜 모드 및 이미지 생성 스킬]**

    - **세부 주제:** `/plan` (Shift+Tab): 코드 개발 전 계획 문서 먼저 작성. 실행 옵션 3가지 — ① 현재 세션 바로 실행, ② 컨텍스트 초기화 후 플랜 실행(권장), ③ 플랜 수정. 피처 단위 개발 시 Option 2 선호
    - **세부 주제:** `$image`: Codex 스킬로 이미지 생성. 구독 요금제에 포함(추가 결제 불필요). 로고·에셋 생성과 개발 워크플로우를 단일 세션에서 통합 처리
    - **세부 주제:** `!`: Codex 세션 내부에서 직접 bash 명령 실행(ls, 에디터 열기 등). 별도 터미널 불필요

*   **[코드 리뷰 및 GitHub 연동]**

    - **세부 주제:** `/review`: 4가지 리뷰 모드 — ① 최신 커밋, ② 브랜치-베이스 비교(커밋 전 셀프 리뷰), ③ 특정 커밋, ④ 커스텀 인스트럭션 리뷰. git status·diff·빌드 에러 자동 확인
    - **세부 주제:** GitHub 연동 PR 리뷰: Codex Cloud에서 GitHub 연결 후 PR 오픈/push 시 자동 리뷰. 리뷰 코멘트에서 Codex 에이전트를 직접 호출해 수정 요청 → 피어 커밋으로 자동 반영

*   **[최종 결론 및 사용 전략]**

    - **세부 주제:** Codex 강점: 같은 작업 대비 토큰 2~3배 절약, 장기 자율 실행 안정성, 터미널 도구 활용도 높음. Claude Code 대비 속도는 느리나 멀티 세션 병렬 운영으로 극복 가능
    - **세부 주제:** 권장 분업: Codex = 계획 수립 단계, 코드 리뷰 단계, 장기 자율 실행 / Claude Code = 일상 개발, 대규모 리팩터링, 빠른 결과 필요 시

## ⏳ 3. 주요 시간대별 상세 요약

*   **[00:00:00] ~ Claude Code 품질 저하 배경 및 영상 개요**

    - Claude Code 답답함을 느끼던 사용자들이 많았고, Anthropic이 공식적으로 품질 저하를 인정. 3가지 원인: ① 기본 추론 난이도 높음→중간 변경, ② 비활성 세션 사고 과정 캐시 초기화, ③ 출력량 절감 목적 시스템 프롬프트 변경 (현재 모두 원상 복구 완료)
    - 이로 인해 Claude Code 사용자들이 Codex로 이동하는 추세 관찰. 영상에서는 Codex 기본 사용법과 초보자도 모르는 꿀팁을 전부 다룸

*   **[00:01:30] ~ OpenAI 업데이트: Image 2.0 및 GPT-5.5**

    - Image 2.0: 한글 텍스트 포함 고품질 이미지 생성 가능 (기존 이미지 생성 모델의 한글 취약점 해결). 브라우저 UI 스크린샷, 과학 잡지 표지, 퍼스널 컬러 보고서 등 다양한 유형 시연
    - GPT-5.5 출시로 Codex CLI 활용 최적 시점. Codex CLI에서 이미지 생성 기능 통합 사용법도 다룰 예정

*   **[00:02:30] ~ Codex 설치 및 기본 실행**

    - npm으로 설치(`npm install -g codex`), `codex` 명령으로 실행. Claude Code와 유사한 터미널 UI
    - `/permissions` 명령: 3가지 모드 선택 — Default(외부 접근 시 승인), Auto Review(서브 에이전트가 안전성 판단), Full Access(완전 자율 실행)
    - `/statusline`: 모델명·reasoning·git 브랜치·컨텍스트 사용량·Fast 모드·프로젝트명 등 원하는 항목 활성화

*   **[00:04:30] ~ 프롬프트 입력 및 큐 예약**

    - 채팅창에 프롬프트 입력 후 Enter로 실행. Tab 키로 현재 작업에 영향 없이 후속 작업 큐 예약 가능(개수 무제한)
    - `/copy` (Ctrl+O): 마지막 응답 클립보드 복사 → 다른 에디터·세션으로 이동해 활용

*   **[00:05:30] ~ 컨텍스트 관리: /clear, 프롬프트 히스토리**

    - `/clear`: 대화 내역 완전 초기화. 컨텍스트 사용량이 높아질수록 에이전트 성능 저하 → 기능 단위로 새 세션 생성 권장
    - 방향키로 이전 프롬프트 탐색, Ctrl+R로 프롬프트 히스토리 검색
    - Ctrl+C(입력 중): 프롬프트 삭제 + 히스토리 저장 → 방향키로 복구. Claude Code의 ESC 역할 (Codex에선 ESC 반응 없음)

*   **[00:07:00] ~ 세션 관리: resume, /fork, /status**

    - `codex resume`: 현재 디렉터리의 이전 세션 목록에서 특정 세션 복구. `--all` 옵션으로 전체 프로젝트 세션 조회
    - `/fork`: 현재 세션을 동일 맥락으로 복제 → 분기 개발 시 유용. resume 명령으로 확인 가능
    - `/status`: 컨텍스트 윈도우 사용량, weekly limit 잔여량 확인. GPT 5.3 Spark 전용 limit 별도 분리

*   **[00:08:30] ~ 모델 설정: Spark, /model, /fast**

    - Codex Spark 모델: 빠른 속도, 일상적 코드 생성에 적합. 별도 한도로 전체 quota 절약
    - `/model`: 모델 변경 및 reasoning 단계 설정. reasoning high 권장
    - `/fast` (기본 OFF): 응답 속도 향상. GPT-5.5는 표준 대비 2.5배, GPT-5.4는 2배 크레딧 소모 주의. GPT-5.5/5.4만 지원

*   **[00:10:00] ~ 플랜 모드 및 이미지 생성 스킬**

    - `/plan` (Shift+Tab 토글): 코드 작성 전 계획 문서 먼저 생성. 모호한 부분은 에이전트가 역질문으로 명확화
    - 실행 옵션: ① 현재 세션 즉시 실행, ② 컨텍스트 초기화 후 플랜 실행(권장 — 필요한 컨텍스트만 유지), ③ 플랜 수정
    - `$image`: 이미지 생성 스킬. 서비스 로고·에셋 생성을 개발 워크플로우 내에서 통합 처리. 구독에 포함
    - `!`: Codex 세션 내에서 bash 명령 직접 실행. 마크다운 프리뷰, 파일 목록 확인, 에디터 실행 등 가능

*   **[00:13:00] ~ /review: 로컬 및 GitHub PR 리뷰**

    - `/review`: 4가지 모드 — ① 최신 커밋, ② 브랜치-베이스 비교(커밋 전 셀프 리뷰 추천), ③ 특정 커밋, ④ 커스텀 인스트럭션 리뷰
    - git status·diff 자동 추적, 로컬 테스트·빌드 에러 확인 후 종합 리뷰 생성
    - GitHub 연동(Codex Cloud): PR 오픈/push 시 자동 리뷰 코멘트 생성. 코멘트에서 Codex 에이전트 직접 호출 → 수정 피어 커밋 자동 반영

*   **[00:16:00] ~ /compact 및 최종 사용 전략**

    - `/compact`: 대화 내역을 핵심 맥락만 추려 압축. /clear(완전 초기화)와 달리 맥락 유지하며 컨텍스트 최적화
    - 최종 결론: Codex 강점 = 토큰 2~3배 절약, 장기 자율 실행 안정성, 비용 효율. 속도 열세는 멀티 세션 병렬 운영으로 극복
    - 권장 분업: **Codex** = 계획 수립·코드 리뷰·장기 자율 실행·백엔드 작업 / **Claude Code** = 일상 개발·빠른 프로토타이핑·대규모 리팩터링
