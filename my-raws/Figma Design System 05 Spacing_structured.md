## 📝 1. 영상 전체 요약

> FDS 시리즈 5화로, 스페이싱의 개념과 역할을 설명하고, 글로벌 8포인트 시스템과 T셔츠 사이징을 기반으로 2px~112px 17단계 스페이싱 변수(Spacing 컬렉션)를 Figma Variables 패널에서 직접 생성한 뒤, 컴포넌트·카드·앱 화면에 적용하는 전체 워크플로우를 다룬다.

## 📖 2. 영상 주요 주제 (추상화된 목차)

*   **[스페이싱의 정의와 디자인 시스템에서의 역할]**

    - **세부 주제:** 스페이싱 = 텍스트·이미지·버튼 등 인터페이스 요소 사이의 공간. 시각적 조화·가독성·사용성을 보장하며 일관된 레이아웃 형성에 핵심.

*   **[글로벌 8포인트 시스템과 T셔츠 사이징 스케일]**

    - **세부 주제:** 8포인트 시스템: 기준 8px을 배수로 곱해 일관된 스페이싱 값 생성. 컴포넌트·콘텐츠·화면 수준에서 동일한 기준 적용.
    - **세부 주제:** T셔츠 사이징(2XS~12XL): 2xs(2px)부터 12xl(112px)까지 17단계. 배수(multiplier)와 픽셀값을 함께 정의하여 명확한 스케일 제공.

*   **[스페이싱 적용 사례: 컴포넌트·카드·화면 레벨]**

    - **세부 주제:** 컴포넌트 레벨 (Input): 레이블↔필드 8px, 필드↔헬프텍스트 8px, 필드 내부 수평 패딩 16px·수직 패딩 12px, 텍스트↔에러아이콘 8px.
    - **세부 주제:** 카드 레벨: 전체 패딩 16px, 헤딩↔본문 8px, 본문↔작성자 정보 16px, 아바타↔작성자 세부 정보 8px.
    - **세부 주제:** 화면(앱 스크린) 레벨: 사이드 마진 24px, 콘텐츠 블록 간격 16px, 헤딩↔텍스트 8px.

*   **[Figma Variables 패널에서 Spacing 컬렉션 생성]**

    - **세부 주제:** 컬렉션 생성: Variables 패널에서 "spacing" 컬렉션 생성 → Number 타입 변수 17개 생성(복제 방식). 그룹명 "space"로 묶어 정리.
    - **세부 주제:** 명명 및 값 할당: T셔츠 사이징 이름(2xs·XS·S·M·L·XL·2XL~12XL) 부여, 값: 2·4·8·12·16·24·32·40·48·56·64·72·80·88·96·104·112.

*   **[스페이싱 변수 적용 및 Dev Mode 확인]**

    - **세부 주제:** 컴포넌트에 변수 적용: 카드 컨테이너 패딩을 space/L(16px)로 지정, 콘텐츠 내부 간격을 space/S(8px)로 지정, 작성자 세부 정보도 space/S 적용.
    - **세부 주제:** Dev Mode: 엔지니어가 Dev Mode를 켜면 적용된 스페이싱 변수를 그대로 확인 가능.

*(참고: 이 항목은 영상의 논리적 구조를 추상화하여 그룹화한 것이며, 시간 정보는 포함되지 않습니다.)*

## ⏳ 3. 주요 시간대별 상세 요약

*   **[00:00:00] ~ 스페이싱이란 무엇인가**

    - 스페이싱 = 텍스트·이미지·버튼 등 UI 요소 간의 공간. 시각적 조화·가독성·사용성 보장.
    - 글로벌 8포인트 시스템: 기준 8px을 배수로 곱해 일관된 값 생성. T셔츠 사이징(2XS~12XL), 배수와 픽셀값 2~112px 17단계.

*   **[00:00:40] ~ 스페이싱 적용 사례 설명**

    - Input 컴포넌트: 레이블↔필드 8px, 필드↔헬프텍스트 8px, 필드 내부 수평 16px·수직 12px, 텍스트↔아이콘 8px.
    - 카드 컴포넌트: 전체 패딩 16px, 헤딩↔본문 8px, 본문↔작성자 정보 16px, 아바타↔작성자 세부 정보 8px.
    - 앱 화면: 사이드 마진 24px, 콘텐츠 블록 간격 16px, 헤딩↔텍스트 8px. 화이트스페이스가 레이아웃 소비성을 높임을 시각적으로 시연(스페이싱 레이어 토글).

*   **[00:01:30] ~ Figma Variables에서 Spacing 컬렉션 생성**

    - Variables 패널에서 "spacing" 컬렉션 생성 → Number 타입으로 첫 변수 생성(값: 2). 복제(Duplicate) 16회로 총 17개 변수 확보.
    - T셔츠 사이징 이름 부여: 2XS, XS, S, M, L, XL, 2XL, 3XL, 4XL, 5XL, 6XL, 7XL, 8XL, 9XL, 10XL, 11XL, 12XL.
    - 값 할당: 2·4·8·12·16·24·32·40·48·56·64·72·80·88·96·104·112(8의 배수 기반, 초기 소수값 포함).
    - 전체 선택 → New Group → "space" 그룹으로 묶기.

*   **[00:03:00] ~ 카드 컴포넌트에 스페이싱 변수 적용**

    - 카드 Container 선택 → 패딩 16 → 변수 아이콘 → space/L(16px) 할당.
    - 콘텐츠 내부 텍스트 간격 → space/S(8px) 할당. 작성자 정보 간격도 space/S 적용.
    - Dev Mode 활성화 시 엔지니어가 적용된 스페이싱 변수값을 직접 확인 가능.
    - 다음 에피소드 예고: Layout & Breakpoints.
