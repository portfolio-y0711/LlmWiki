## 📖 2. 영상 주요 주제 (추상화된 목차)

*   **[도입 — AI 기반 비즈니스 시각화의 가능성]**

    - **세부 주제:** 코딩 에이전트의 시각적 사고 능력: Claude가 JSON 좌표·색상 코드 형태로 Excalidraw 다이어그램을 생성할 수 있으며, 이를 통해 비즈니스 구조를 명확히 시각화할 수 있음.
    - **세부 주제:** 시각화의 비즈니스 가치: 마인드맵·수영레인·프로세스 플로우를 통해 AI 에이전트·디지털 자산·자동화 도입 지점을 발견하는 전략적 관점 제공.

*   **[Excalidraw 스킬 — 핵심 기능과 토큰 주의사항]**

    - **세부 주제:** Excalidraw 스킬 사용법: GitHub에서 무료 제공되는 스킬을 Claude에 로드한 뒤 프롬프트로 마인드맵·수영레인 생성. JSON 코드 형태로 출력되어 excalidraw.com에서 로컬 파일을 열어 렌더링.
    - **세부 주제:** 토큰 비용 주의: Excalidraw JSON은 코드 형식이라 대량의 토큰을 소비하므로, 복잡한 수영레인 생성은 최상위 플랜 이용자에게만 권장.
    - **세부 주제:** 시각화 예시: 디지털 자산 에코시스템 마인드맵(상품 시스템·AI 에이전트·IP·브랜드·마케팅 자산), 고객→디지털 자산→AI 에이전트→오너 흐름의 수영레인 다이어그램.

*   **[draw.io — 효율적 대안 도구]**

    - **세부 주제:** Excalidraw vs draw.io 비교: draw.io는 XML 포맷 기반으로 Excalidraw 대비 토큰 소비가 적고, 네이티브 시각화에 더 적합하며 결과물이 더 깔끔함.
    - **세부 주제:** draw.io 실전 데모: Claude에게 "draw.io swim lane을 XML로 생성해줘" 요청 → 파일 다운로드 후 draw.io에서 열기 → 색상 등 속성을 Claude에게 추가 지시하여 즉시 업데이트.
    - **세부 주제:** 비즈니스 인사이트 도출: '전통적 운영 방식(오너 5개 수작업)' vs '레버리지 방식(AI·디지털 자산 활용, 오너 3개 고부가 결정만)' 수영레인 비교로 구조적 병목 시각화.

*   **[Claude Code + VS Code 통합 — 인터랙티브 편집]**

    - **세부 주제:** VS Code 확장 설치: Excalidraw 확장과 draw.io 확장을 설치하면 Claude Code가 로컬 `.excalidraw` 및 `.drawio` 파일을 직접 생성·편집 가능. 매번 다운로드·업로드 불필요.
    - **세부 주제:** 인터랙티브 비즈니스 맵 구축: 하이레벨 수영레인 → 세부 프로세스 플로우 → 추가 페이지 확장 순서로 Claude Code와 대화하며 비즈니스 전체 맵을 누적 구축.
    - **세부 주제:** 실시간 수정 워크플로우: 프로세스 변경 시 Claude Code에 자연어로 지시하면 XML 파일을 직접 편집. 색상·텍스트·구조 변경 모두 즉시 반영.

*   **[결론 — 비즈니스 구조화와 AI 기회 발견]**

    - **세부 주제:** 비즈니스 맵의 전략적 활용: 전체 비즈니스를 시각화함으로써 제거(Eliminate)·위임(Delegate)·단순화(Simplify)·자동화(Automate) 대상을 명확히 식별.
    - **세부 주제:** 비즈니스 엑스레이 에이전트 스킬: 인터뷰 방식으로 사용자의 비즈니스 내용을 추출하고 AI가 자동으로 비즈니스 맵을 구성해주는 스킬 소개.

## ⏳ 3. 주요 시간대별 상세 요약

*   **[00:00:00] ~ 도입 — AI가 비즈니스를 시각적으로 사고하다**

    - Claude가 마인드맵과 프로세스 다이어그램을 수분 내 생성 가능하며, 이는 비즈니스 구조를 명확히 보고 AI·자동화·시스템 도입 지점을 발견하는 데 활용 가능.
    - 영상 구성 예고: ① Excalidraw 스킬(Claude 웹앱), ② Claude Code에서의 사용법, ③ 최선의 대안인 draw.io + Claude Code 통합.

*   **[00:01:30] ~ Excalidraw 스킬 데모 — 마인드맵 생성**

    - 무료 Excalidraw 스킬을 로드한 뒤 프롬프트로 디지털 자산 에코시스템 마인드맵 생성. 출력은 JSON 형태로, 이것이 Claude가 시각적으로 사고할 수 있는 이유(좌표·색상 등 숫자 데이터).
    - 주의: JSON 생성 특성상 토큰 소비가 매우 많음. 복잡한 수영레인 생성은 최상위 플랜 이용자에게만 권장.
    - 결과물: 비즈니스에 필요한 디지털 자산 유형(상품 시스템·AI 에이전트·IP·브랜드·마케팅 자산)을 한눈에 파악하는 마인드맵.

*   **[00:04:00] ~ draw.io 대안 — 더 효율적인 시각화**

    - Excalidraw(손그림 스타일) vs draw.io(네이티브 시각화) 선택지 제시. 크리에이터 본인은 draw.io 선호.
    - 요청 방식: "draw.io swim lane을 XML로 만들어줘" → XML 파일 다운로드 → draw.io에서 열기.
    - 결과 비교 다이어그램: '전통 방식(오너가 리드 응대·일정 조율·제안서 작성 등 모든 수작업)' vs '레버리지 방식(디지털 자산·AI 에이전트가 작업 수행, 오너는 고부가 의사결정 3개만)'. 이 시각화를 통해 비즈니스 병목과 개선 지점을 즉시 파악.

*   **[00:07:00] ~ Claude Code + VS Code 통합 설정**

    - VS Code에서 Excalidraw 확장 및 draw.io 확장 설치 방법 시연.
    - 설치 후 `.excalidraw` 파일과 `.drawio` 파일을 VS Code 내에서 직접 렌더링·편집 가능. Claude Code가 파일을 직접 수정하므로 매번 다운로드·업로드 불필요.

*   **[00:08:30] ~ Claude Code로 Excalidraw 프로세스 플로우 생성**

    - 슬래시 커맨드 기반 워크플로우(기사 변환 프로세스)를 대상으로 Excalidraw 프로세스 플로우 다이어그램 생성 데모.
    - 결과물: URL 입력 → 시스템 처리 단계 → 최종 출력까지의 전체 프로세스를 시각화. VS Code 내에서 실시간 편집 가능.

*   **[00:10:00] ~ Claude Code로 draw.io 프로세스 다이어그램 + 수영레인 생성**

    - 동일 워크플로우를 draw.io로 재생성. Phase 0~5 구조와 범례가 포함된 프로세스 다이어그램 출력.
    - 인터랙티브 편집 데모: "다크블루를 라이트블루로 바꿔줘" → Claude Code가 XML 즉시 수정 → draw.io에서 색상 변경 반영 확인.
    - 추가 요청: 기존 다이어그램을 두 번째 페이지에 수영레인으로 변환 → 오케스트레이터·서브에이전트·도구·파일 구조를 시각화. AI 에이전트 컨텍스트 초과 시 서브에이전트 위임 구조를 설계하는 데 활용 가능.

*   **[00:13:00] ~ 비즈니스 맵 누적 구축 워크플로우**

    - 하이레벨 콘텐츠 생성 워크플로우 수영레인 → 특정 프로세스 세부 확장 → 추가 프로세스 플로우 다이어그램 순서로 Claude Code와 대화하며 비즈니스 전체 맵 누적 구축 방식 소개.
    - Claude Code가 기존 파일을 읽고 그 위에 추가 구축 가능하므로, 사용자와 AI가 함께 점진적으로 비즈니스 맵을 발전시킬 수 있음.

*   **[00:15:00] ~ 결론 및 비즈니스 엑스레이 에이전트**

    - 비즈니스 시각화의 전략적 가치: 제거·위임·단순화·자동화 대상 명확화 → AI 에이전트 도입으로 오너의 실행 시간 최소화. Naval Ravikant 인용 "시간이 아닌 지성으로 보상받아라."
    - 비즈니스 엑스레이 에이전트 스킬 소개: 인터뷰 방식으로 비즈니스 내용을 추출하고 AI가 자동으로 비즈니스 맵과 AI 도입 기회를 도출해주는 스킬.
