## 📝 1. 영상 전체 요약

> Claude Design을 실제 비즈니스(Agentic Academy)에 적용하는 라이브 빌드를 통해, AI 슬롭을 피하는 핵심 원칙(디자인 시스템 선행 구축·AI 금지 패턴 명시·인라인 코멘트 활용·영상→슬라이드 변환)을 도출하고, 랜딩 페이지·모바일 와이어프레임·슬라이드 덱을 Claude Design과 Claude Code의 조합으로 완성하는 실전 워크플로우를 제시한다.

## 📖 2. 영상 주요 주제 (추상화된 목차)

*   **[Claude Design의 본질 이해: AI 슬롭의 원인]**

    - **세부 주제:** Claude Design의 정체: 모든 산출물이 코드로 생성됨. Canva 같은 드래그앤드롭 도구가 아니라 Claude Code와 같은 엔진. 에셋 디자인(Canva 영역) vs. 시스템 디자인(Figma·Claude Design 영역) 구분
    - **세부 주제:** 90/10 규칙: AI가 90%까지 빠르게 도달하지만 마지막 10%(커스텀 마이크로카피, 정확한 아이콘, 인간의 취향)는 여전히 사람이 필요. "Claude Design이 최종 결과물을 완성한다"고 기대하면 실망
    - **세부 주제:** AI 슬롭의 구조적 원인: Claude Design은 내부적으로 Anthropic의 프론트엔드 디자인 스킬을 사용. 루스 프롬프트를 주면 기본 프리셋(따뜻한 크림·오프화이트 배경, Serif 폰트, 컬러 액센트 바, 블링킹 그린 닷)으로 폴백. Anthropic 공식 문서에도 "Opus 4.7에는 따뜻한 크림 배경의 하우스 스타일이 내장됨"이라고 명시

*   **[디자인 시스템 구축: 3가지 접근법과 토큰 절약 전략]**

    - **세부 주제:** 핵심 원칙: 디자인 시스템을 먼저 구축하는 것이 가장 중요한 단계. Ryan Mather(Anthropic 디자인팀): "처음 1~2시간을 디자인 시스템 설정에 투자하라 — 고통스럽지만 나중에 10배로 돌아온다"
    - **세부 주제:** Method 1 — 레퍼런스 스크린샷 + ChatGPT Image: 마음에 드는 웹사이트(Zeno, Stack AI 등) 스크린샷을 ChatGPT Image 2.0에 업로드 → "디자인 시스템 원페이저 생성" 요청 → AI 금지 패턴(Inter 폰트 등) 명시 → 다듬어진 결과물을 Claude Design에 입력. Claude Design 토큰을 사고 단계에 낭비하지 않는 효과
    - **세부 주제:** Method 2 — Skill UI CLI: `npm install -g skill-ui`로 설치 후 원하는 웹사이트 URL을 입력하면 색상 토큰·타이포그래피·컴포넌트·애니메이션·스크롤 스크린샷을 추출해 `design.md`와 스킬 폴더 자동 생성. API 키 불필요, 완전 정적 분석
    - **세부 주제:** 토큰 절약 전략: Claude Design 토큰 한도는 Claude Code·Chat와 별도로 관리됨. 디자인 시스템 작업 외부(ChatGPT·Skill UI)에서 처리하고 완성된 결과물만 Claude Design에 입력하면 Max 20x 플랜 기준 두 개 디자인 시스템 생성 후에도 25%만 소진

*   **[디자인 시스템 인터랙션: 컴포넌트 승인 및 정제]**

    - **세부 주제:** Claude Design 인터페이스: 각 컴포넌트(색상·타이포그래피·버튼·폼·마케팅 키트)를 하나씩 "Looks Good" 또는 "Needs Work"로 승인. "Needs Work" 클릭 시에만 토큰 소비 — 특정 요소를 타겟팅해 피드백함으로써 전체 재프롬프트보다 토큰 절약
    - **세부 주제:** Taste 스킬 활용: Leon이 제작한 Taste 스킬에서 "AI Tells"(금지 패턴 목록 — Inter 폰트, Roboto, 제네릭 그라디언트, Teal 색상 등)를 복사 → ChatGPT 또는 Claude Design 프롬프트에 첨부해 기본 AI 미학 차단

*   **[랜딩 페이지 빌드: Claude Design vs. Claude Code 비교]**

    - **세부 주제:** Claude Design으로 랜딩 페이지 생성: 선택한 디자인 시스템 + 스크린샷 + 상세 구조 설명 → 결과물이 AI 생성 느낌 없이 깔끔하게 출력. 인라인 코멘트로 특정 요소(헤더 크기·가격 텍스트·반응형 레이아웃) 개별 수정 가능. 직접 편집 모드(토큰 소비 없이 텍스트 수정) 지원
    - **세부 주제:** Claude Code(Skill UI 폴더) 비교: 같은 스택AI 디자인 시스템으로 직접 빌드 시 유사한 품질의 랜딩 페이지 생성 가능. 차이점: Claude Code는 코드베이스를 뒤져야 특정 요소를 수정 가능 vs. Claude Design은 화면 위에서 직접 요소를 클릭해 코멘트 가능
    - **세부 주제:** 최종 10% 폴리시 — Taste 스킬 Redesign: `npx skills add taste-skill` 설치 → Claude Code에서 HTML 파일에 `/redesign` 스킬 적용 → 타이포그래피 웨이트 다양화, 비-라운드 숫자(1,200→1247), 스쿼클 아바타(원형 대신), FAQ 아코디언 교체 등 AI 특징 제거. Brutalist/Minimalist 스킬도 활용 가능

*   **[모바일 와이어프레임: Claude Design의 질문 기반 설계]**

    - **세부 주제:** Claude Design의 질문 기반 인터랙션: 개방적 브리프를 주면 Claude가 먼저 다수의 명확화 질문을 던짐(스케치 vs. 실제 디자인, 와이어프레임할 화면, 화면당 변형 수, 네비게이션 패턴 등) — Claude Code와 달리 대화형 기획 단계 제공
    - **세부 주제:** Tweaks 기능: 와이어프레임 완성 후 라이트/다크 모드·스케치/클린 스트로크·주석 온오프 등을 실시간 토글하며 비교 가능. 화면당 2~3가지 변형 요청 가능
    - **세부 주제:** 결과: 4%의 토큰으로 6개 주요 화면 × 2변형 와이어프레임 생성. "디자이너가 아닌 사람도 몇 분 만에 개발자에게 넘길 수 있는 코드 기반 목업 완성"

*   **[슬라이드/영상 덱: 영상 먼저 만들기 전략]**

    - **세부 주제:** 피터 양 팁: 슬라이드 덱을 직접 요청하면 정적이고 제네릭하게 나옴 → 먼저 애니메이션 영상 요청 → 완성된 영상 프로젝트를 복제 → 슬라이드 덱으로 변환 요청. 영상은 동적으로 설계되므로 이를 슬라이드로 변환하면 더 생동감 있는 결과물
    - **세부 주제:** 실전 예시: YouTube 영상 스크립트를 붙여넣어 "7 Levels of Claude Code" 애니메이션 영상 생성 → 프로젝트 복제 → "슬라이드 덱으로 변환, 스크린샷 첨부" 요청 → 각 레벨별 인터랙티브 슬라이드로 완성

*(참고: 이 항목은 영상의 논리적 구조를 추상화하여 그룹화한 것이며, 시간 정보는 포함되지 않습니다.)*

## ⏳ 3. 주요 시간대별 상세 요약

*   **[00:00:00] ~ 도입: Claude Design의 정체와 목표]**

    - 영상 목표: 원샷 데모 대신 실제 비즈니스(Agentic Academy) 실제 문제 해결에 Claude Design 사용
    - 해결할 문제: 제대로 된 랜딩 페이지 없음, Command Center에 모바일 버전 없음, 일관된 슬라이드 덱 없음
    - Claude Design의 본질: 모든 산출물이 코드. "Figma 대체"나 "Canva 대체"가 아니라 시스템 디자인 도구. Peter Yang: "Videos, slides, websites, apps — 다 코드, 같은 AI"

*   **[00:02:30] ~ AI 슬롭 문제와 디자인 시스템의 중요성]**

    - Reddit 불만: "Claude Design은 하나의 룩만 있다" — Serif 폰트, 컬러 액센트 바, 블링킹 그린 닷
    - 원인: 루스 프롬프트 → 기본 프리셋 폴백. Anthropic 공식 문서: "Opus 4.7에 따뜻한 크림 배경 하우스 스타일 내장"
    - Ryan Mather 팁: "처음 1~2시간을 디자인 시스템 설정에 투자하라"
    - 주의: 디자인 시스템 설정이 가장 많은 토큰을 소비. 한 세션에 집중해서 진행할 것

*   **[00:05:00] ~ Method 1: ChatGPT Image로 디자인 시스템 원페이저 생성]**

    - 영감 수집: Zeno.com(오렌지 레드), Stack AI(클린·라운드 엣지·그림자 카드), Landbook·Dribbble
    - ChatGPT Image 2.0에 스크린샷 + "디자인 시스템 원페이저 생성" 요청 → Taste 스킬 "AI Tells" 섹션(Inter 폰트 금지 등) 추가 → 점진적 정제
    - 목적: Claude Design 토큰을 사고 단계에 쓰지 않고 이미 검토된 디자인을 주입

*   **[00:10:00] ~ Method 2: Skill UI로 웹사이트 디자인 시스템 역공학]**

    - 설치: `npm install -g skill-ui` + Playwright + Chromium
    - 실행: `skill-ui --url stackai.com --mode ultra` → 색상 토큰·CSS 변수·타이포그래피·컴포넌트·애니메이션·스크롤 스크린샷 추출 → `design.md` + 스킬 폴더 자동 생성
    - API 키 불필요. 완전 정적 분석. 수 분 내 완료
    - 활용: Claude Code에서 해당 폴더 안에서 바로 "Build me a landing page based on this design"으로 사용 가능 (Claude Design 없이도 됨)

*   **[00:16:00] ~ Claude Design에 디자인 시스템 입력 및 승인]**

    - claude.ai/design → 새 디자인 시스템 생성 → 로고·폰트·토큰 파일·design.md 업로드
    - 두 가지 시스템 비교: ChatGPT 생성 vs. Skill UI 추출(Stack AI 에뮬레이션)
    - 인터랙션: 각 컴포넌트 카드를 "Looks Good(토큰 소비 없음)" 또는 "Needs Work(피드백 입력, 토큰 소비)"로 분류
    - 결론: Skill UI로 추출한 시스템이 더 깔끔. 진행 선택

*   **[00:25:00] ~ 랜딩 페이지 생성 및 반복 편집]**

    - 프롬프트 전략: 선택한 디자인 시스템 + 기존 광고 페이지 섹션별 스크린샷 + "디자인 시스템 기반으로, 스크린샷 구조 아닌 디자인 반영"
    - 결과: 텍스트 레이아웃 개선, 기존 이미지를 새 컬러 팔레트로 재해석, 반응형 미흡 부분 존재
    - 인라인 코멘트 활용: 헤더 크기 축소(2% 토큰), 가격 텍스트 수정, 이미지 크기 조정
    - 직접 편집 기능: 텍스트를 AI 없이 직접 수정 가능(WordPress/Webflow/Framer 방식)

*   **[00:40:00] ~ Claude Code vs. Claude Design 비교 및 Taste 스킬 최종 폴리시]**

    - Skill UI 폴더에서 Claude Code 직접 빌드: 유사한 품질이나 특정 요소 수정 시 코드베이스 탐색 필요
    - Claude Design의 강점: 화면 위에서 특정 요소 클릭 → 코멘트 → 수정, 디자인 파일 레벨 피드백
    - Claude Design → "Share" → "Handoff to Claude Code" → 독립 HTML 다운로드
    - Taste 스킬 `/redesign` 적용: 비-라운드 숫자, 타이포그래피 다양화, 스쿼클 아바타, FAQ 재설계 — 그러나 일부 요소(로고 변경 등) 부작용 발생
    - Brutalist 스킬: "다크 크로매틱 + 액센트 레드 + 코드 텍스트 스타일"로 완전히 다른 분위기 — AI 생성 느낌 없음

*   **[00:55:00] ~ 모바일 와이어프레임: 질문 기반 인터랙션]**

    - 오픈 브리프 입력 → Claude가 질문 목록 제시: 스타일, 와이어프레임할 화면, 화면당 변형 수, 네비게이션 패턴, 모바일에서 새 목표 생성 방법 등
    - Tweaks 기능: 라이트/다크·스케치/클린·주석 온오프 실시간 토글
    - 결과: 6개 화면 × A/B 변형 와이어프레임. 42% 토큰 도달(4% 추가 소비). 개발자에게 바로 넘길 수 있는 HTML/CSS 기반 목업
    - "디자이너가 아닌 사람도 수 분 만에 완성. 이걸 디자이너가 직접 하면 몇 시간?"

*   **[01:10:00] ~ 슬라이드 덱: 영상 먼저 만들기 전략]**

    - 피터 양 팁: 슬라이드 직접 요청 → 정적·제네릭. 대신 애니메이션 영상 먼저 요청 → 복제 → 슬라이드 변환
    - 실행: YouTube 스크립트 붙여넣기 → "7 Levels of Claude Code" 애니메이션 영상 생성(62% 토큰). Shift+Tab으로 모드 전환, 각 레벨별 코딩 플랫폼 애니메이션 포함
    - 슬라이드 변환: 프로젝트 복제 → "슬라이드 덱으로 변환, 스크린샷 첨부" → 각 레벨별 인터랙티브 슬라이드 + Boris Cherney 트윗 임베드

*   **[01:25:00] ~ 총 결산 및 핵심 팁 4가지]**

    - 최종 토큰 사용: Max 20x 플랜 기준 70%로 랜딩 페이지 + 와이어프레임 + 슬라이드 덱 완성. 모두 AI 슬롭 아닌 프로페셔널 결과물
    - 핵심 팁 ①: 항상 디자인 시스템 먼저 구축 — 인간적 요소를 선행 추출해 Claude에 주입
    - 핵심 팁 ②: AI 금지 패턴 명시 — Inter/Roboto 폰트 금지, 제네릭 그라디언트 금지, Teal 색상 금지
    - 핵심 팁 ③: 인라인 코멘트 활용 — 전체 재프롬프트 대신 특정 요소 타겟팅 편집
    - 핵심 팁 ④: 동적 덱은 영상 먼저 생성 후 슬라이드로 변환
    - 현재 최대 한계: 커스텀 스킬 임포트 불가 → Claude Code + Claude Design 조합으로 우회
