## 📝 1. 영상 전체 요약

> Figma Design System 시리즈 9번째 에피소드로, 아이콘의 사이즈 규칙·스트로크 가중치·트림 영역 등 아이코노그래피의 핵심 원칙을 정리하고, **Feather Icons**를 기반 아이콘 세트로 도입한 뒤, UFO 아이콘을 직접 제작하는 과정을 통해 FDS의 아이콘 제작 워크플로우 전체를 실습한다.



---

## 📖 2. 영상 주요 주제 (추상화된 목차)

*   **도입 — 아이콘의 역할과 사이즈 원칙**

    - **세부 주제:** 아이콘 정의 — 텍스트 없이 인터페이스 탐색·액션·기능 이해를 돕는 소형 시각 요소
    - **세부 주제:** 사이즈 규칙 — 아이콘은 제작된 크기 그대로 사용하는 원칙 (16 / 24 / 32 / 64~96px 픽토그램)
    - **세부 주제:** 크기별 스트로크 가중치 및 트림 영역(trim area) 기준표

*   **핵심 구조 — 아이콘 제작 5단계 프로세스**

    - **세부 주제:** 1~2단계: 정해진 픽셀 프레임 생성 및 명명 규칙(`icon/name/size`) 적용, 기본 도형으로 드로잉
    - **세부 주제:** 3~4단계: 모서리 라운딩·조인 처리 후 전체 플래튼(flatten), `content-primary` 시맨틱 변수 할당
    - **세부 주제:** 5단계: 가이드 삭제 후 컴포넌트로 전환하여 아이콘 세트에 추가

*   **기반 아이콘 세트 도입 — Feather Icons 활용**

    - **세부 주제:** Feather Icons(Co Beamus 제작, Thomas Peroff가 16·32px 확장) 무료 라이브러리 선택 배경
    - **세부 주제:** 제공 사이즈(16 / 24 / 32 + 상태 아이콘), 단일 레이어 플래튼 및 content-primary 변수 적용 상태
    - **세부 주제:** 상태(Status) 아이콘의 다크 모드 대응 — content-info + content-primary-inverse 조합

*   **심화 활용 — UFO 아이콘 직접 제작 실습**

    - **세부 주제:** Oval(타원)로 UFO 몸체와 조종석 형태 잡기, 핀 툴로 곡선 편집
    - **세부 주제:** 선(Line) 세 개로 안테나 제작, 플래튼 문제 해결 및 교차점 처리
    - **세부 주제:** End Point·Join을 Round로 설정, 스트로크 1→1.5px 수정, content-primary 변수 적용
    - **세부 주제:** 레이어 명명(`icon/ufo/24`), 프레임 전환, 컴포넌트 생성 및 아이콘 세트 배치

*   **결론 — 숙제 제시 및 다음 에피소드 예고**

    - **세부 주제:** UFO 16 / 32px 버전 제작을 시청자 숙제로 제시
    - **세부 주제:** 다음 에피소드 예고: **Variable Scoping(변수 스코핑)**

*(참고: 이 항목은 영상의 논리적 구조를 추상화하여 그룹화한 것이며, 시간 정보는 포함되지 않습니다.)*

## ⏳ 3. 주요 시간대별 상세 요약

*   **[00:00:00] ~ 에피소드 소개 및 아이콘 개념**

    - FDS 시리즈 9번째 에피소드, 지금까지의 작업(Design Tokens Library)에서 **Iconography Library**로 이동
    - 아이콘 정의: 버튼·툴바·메뉴 등 인터랙티브 요소에서 텍스트 없이 사용자 경험을 보조하는 소형 시각 요소
    - 사이즈 원칙: 아이콘은 제작된 크기 그대로 사용해야 함 (24px 아이콘을 32px로 강제 리사이즈 금지)
    - 크기가 커질수록 스트로크 가중치 증가, 트림 영역(trim area)으로 아이콘이 컨테이너 가장자리에 닿지 않도록 처리

*   **[00:02:00] ~ 크기별 스트로크·트림 영역 기준**

    - **홈 아이콘 예시 기준표:**
        - 16px: 스트로크 1px, 트림 1px
        - 24px: 스트로크 1.5px, 트림 2px
        - 32px: 스트로크 2px, 트림 2px
        - 64px: 스트로크 3px, 트림 4px
    - 크기가 커질수록 스트로크와 트림 모두 비례 증가

*   **[00:02:45] ~ 아이콘 제작 5단계 프로세스 (24px 캘린더 아이콘 예시)**

    - **1단계 — 프레임:** 24×24px 프레임 생성, 명명 규칙: `icon/calendar/24`
    - **2단계 — 드로잉:** 기본 도형(프리미티브)으로 아이콘 구성, 픽셀 스냅, 스트로크 1.5px
    - **3단계 — 형태 수정:** 조인(join)·포인트를 Rounded로 변경, 모서리에 border radius 적용
    - **4단계 — 플래튼 & 스타일:** 전체 선택 후 Flatten, `content-primary` 시맨틱 변수 레이어에 할당
    - **5단계 — 컴포넌트 생성:** 가이드 삭제 후 컴포넌트로 전환, 아이콘 세트에 추가

*   **[00:04:00] ~ Feather Icons 기반 세트 도입**

    - FDS는 무료이므로 무료 아이콘 라이브러리 **Feather Icons** 채택
        - 원본(24px): Co Beamus 제작
        - 16 / 32px 확장: Thomas Peroff 제작
    - 제공 구성: 세 가지 크기(16 / 24 / 32)의 세트 + 각 크기별 상태(Status) 아이콘
    - 모든 아이콘: 단일 레이어로 플래튼, `content-primary` 변수 적용 완료 → 향후 색상 변경 용이(브랜드/알림/긍정 상태 등)
    - 상태 아이콘 구조: Info 아이콘 배경=`content-info`, 눈=`content-primary-inverse` → 다크 모드 자동 전환 지원

*   **[00:05:30] ~ UFO 아이콘 제작 시작 — 몸체 형태 잡기**

    - 285개 아이콘 세트에 UFO 없음 → 직접 제작
    - 아이콘 사이즈 템플릿(16 / 24 / 32 / 64 지원) 열고 24px 선택
    - **Oval(타원)**으로 UFO 하단 몸체 드로잉, 내부 정사각형 안에 맞도록 크기 조절
    - Fill 제거, 스트로크 Black·Center 설정
    - Command+D로 타원 복제 후 크기 조절해 조종석(캐노피) 형태 생성
    - 핀 툴(Edit Mode) + Option 클릭으로 불필요한 포인트 제거, 곡선 조정

*   **[00:08:00] ~ UFO 안테나(다리) 제작 및 마무리**

    - Alt+L로 Line 툴 사용, 세 개의 선으로 UFO 하단 안테나 제작
    - 선 복제(Command+D) 후 간격·각도 조정
    - 선 길이 조절하여 중앙 안테나가 더 길게, 양쪽 안테나는 짧게 구성
    - 전체 선택 후 Flatten 시도 → 아직 개별 요소로 유지 (예상치 못한 동작)
    - 우클릭 → Edit Object로 접근 후 핀 툴로 교차점 처리
    - Edit Mode에서 불필요한 포인트 삭제로 깔끔한 교차선 완성

*   **[00:10:30] ~ 스트로크 설정 및 컴포넌트 완성**

    - 전체 선택 → End Points: **Round**, Join: **Round** 설정
    - 스트로크 1px → **1.5px**로 수정 (100% 줌에서 선명하게 보이도록)
    - `content-primary` 시맨틱 변수 적용
    - 레이어 이름: `icon/ufo/24`, 레이어 타입을 Frame으로 변경
    - 가이드 템플릿 삭제 후 **컴포넌트 생성**
    - Assets → Icons → icon → UFO에서 24px 버전 확인

*   **[00:12:00] ~ 숙제 및 다음 에피소드 예고**

    - UFO 아이콘 16px·32px 버전 제작은 시청자 숙제로 제시
    - 각 크기 원칙에 맞게 스트로크·트림 조정하여 전체 세트 완성 권장
    - 다음 에피소드 예고: **Variable Scoping(변수 스코핑)**
