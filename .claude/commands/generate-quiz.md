학습 자료 파일을 분석하여 퀴즈와 정답지를 생성합니다.

**입력값:** $ARGUMENTS
(형식: `<파일경로1> [파일경로2] ...`)

다음 순서로 정확히 실행하세요:

## 1단계 — 입력 파싱 및 파일 읽기

`$ARGUMENTS`에서 파일 경로 목록을 파싱합니다. 경로에 공백이 포함된 경우 따옴표로 감싸인 것으로 간주합니다.

각 파일을 읽고 내용을 합산합니다.
- 파일이 존재하지 않으면 사용자에게 알리고 중단합니다.
- 파일이 하나도 없으면 중단합니다.

**출력 파일명 결정:**
- 첫 번째 파일 경로에서 기본 이름을 추출합니다.
- 예: `my-raws/Figma Design System 01 Structure.md` → `figma-design-system-01-structure`
- 규칙: 소문자 변환, 공백→하이픈, 특수문자 제거, `.md` 확장자 제거
- 퀴즈 파일: `quiz/<기본이름>-quiz.md`
- 정답 파일: `quiz/<기본이름>-answers.md`

## 2단계 — 퀴즈 생성 에이전트 프롬프트 읽기

`my-agents/quiz-generator-agent.md` 파일을 읽어 퀴즈 생성 지침을 로드합니다.

## 3단계 — 퀴즈 및 정답 생성

에이전트 프롬프트의 규칙에 따라 읽어들인 학습 자료를 분석하고:

1. **퀴즈 파일** 생성 (`quiz/<기본이름>-quiz.md`)
   - 1부 객관식 7문제 (Q1~Q7)
   - 2부 O/X 3문제 (Q8~Q10)
   - 3부 빈칸 채우기 3문제 (Q11~Q13)
   - 4부 단답형 3문제 (Q14~Q16)
   - 5부 서술형 2문제 (Q17~Q18)
   - 정답 파일명 참조 링크 포함

2. **정답 파일** 생성 (`quiz/<기본이름>-answers.md`)
   - 각 파트별 정답 및 해설
   - 서술형 모범 답안
   - 채점 기준표 (100점 만점)
   - 점수대별 평가 기준

`quiz/` 디렉토리가 없으면 먼저 생성합니다.

## 4단계 — 결과 보고

아래 형식으로 결과를 출력합니다:

```
✅ 퀴즈 생성 완료!

📝 퀴즈:   quiz/<기본이름>-quiz.md    (18문제 / 100점)
✅ 정답지: quiz/<기본이름>-answers.md

문제 구성:
  1부 객관식  Q1~Q7   (35점)
  2부 O/X     Q8~Q10  (15점)
  3부 빈칸    Q11~Q13 (15점)
  4부 단답    Q14~Q16 (15점)
  5부 서술    Q17~Q18 (20점)

분석한 파일: <읽어들인 파일 목록>
```
